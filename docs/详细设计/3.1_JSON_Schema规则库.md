# 3.1 JSON Schema 规则库

## 3.1.1 概述

JSON Schema 规则库是本系统的校验基础设施，用于约束 AI 生成结果符合 DaoSCADA 平台规范。规则库严格遵循 **JSON Schema Draft-07** 标准，以独立 Schema 文件 + 枚举字典 + 校验规则三部分构成，确保生成内容的字段完整性、类型正确性、枚举合法性和结构一致性。

### 核心设计原则

1. **Schema 驱动校验** — 每个 JSON 都必须通过对应 Schema 检验，字段缺失、类型错误、多余字段均判为非法
2. **枚举硬编码** — 所有枚举值以独立字典文件维护，AI 不得生成字典外的值
3. **分层校验** — Schema 校验 → 枚举校验 → 布局/绑点规则校验，逐层过滤
4. **可修复** — 校验报告附带修改建议，支持自动修复和 Agent 修复

### 组态 JSON 三层结构

所有组态界面 JSON 统一采用以下顶层骨架：

```json
{
  "canvas": {},
  "control": [],
  "binding": []
}
```

- `canvas` — 画布配置（尺寸、图层、属性）
- `control` — 控件列表（画面中所有控件的索引和属性）
- `binding` — 绑点列表（控件属性与 PLC 变量的映射关系）

## 3.1.2 Canvas Schema

**文件位置**：`data/canvas_schema.json`

画布顶层结构，描述组态画面的全局配置。

### Schema 定义

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "$id": "canva",
  "title": "Canva",
  "type": "object",
  "required": ["v", "p", "a", "d", "contentRect"],
  "properties": {
    "v": { "type": "string", "description": "版本号" },
    "p": {
      "type": "object",
      "required": ["layers", "autoAdjustIndex", "hierarchicalRendering"],
      "properties": {
        "layers": {
          "type": "array",
          "items": {
            "type": "object",
            "required": ["name", "visible", "selectable", "movable", "editable"],
            "properties": {
              "name": { "type": "string" },
              "visible": { "type": "boolean" },
              "selectable": { "type": "boolean" },
              "movable": { "type": "boolean" },
              "editable": { "type": "boolean" }
            }
          }
        },
        "autoAdjustIndex": { "type": "boolean" },
        "hierarchicalRendering": { "type": "boolean" }
      }
    },
    "a": {
      "type": "object",
      "required": ["width", "height", "fitContent", "rectSelectable", "pannable", "zoomable"],
      "properties": {
        "width": { "type": "number" },
        "height": { "type": "number" },
        "fitContent": { "type": "boolean" },
        "rectSelectable": { "type": "boolean" },
        "pannable": { "type": "boolean" },
        "zoomable": { "type": "boolean" }
      }
    },
    "d": { "type": "array", "description": "数据数组" },
    "contentRect": {
      "type": "object",
      "required": ["x", "y", "width", "height"],
      "properties": {
        "x": { "type": "number" },
        "y": { "type": "number" },
        "width": { "type": "number" },
        "height": { "type": "number" }
      }
    }
  }
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `v` | string | ✅ | 版本号，如 `"8.0.5"` |
| `p.layers` | array[object] | ✅ | 图层定义数组，每项含 name/visible/selectable/movable/editable |
| `p.autoAdjustIndex` | boolean | ✅ | 是否自动调整图层索引 |
| `p.hierarchicalRendering` | boolean | ✅ | 是否分层渲染 |
| `a.width` | number | ✅ | 画布宽度 |
| `a.height` | number | ✅ | 画布高度 |
| `a.fitContent` | boolean | ✅ | 是否自适应内容 |
| `a.rectSelectable` | boolean | ✅ | 是否支持矩形框选 |
| `a.pannable` | boolean | ✅ | 是否支持拖拽平移 |
| `a.zoomable` | boolean | ✅ | 是否支持缩放 |
| `d` | array | ✅ | 控件数据数组 |
| `contentRect` | object | ✅ | 内容矩形区域（x/y/width/height） |

### 约束说明

- `p.layers` 为有序数组，至少需要 1 个图层
- `a.width` 和 `a.height` 建议值为 800–1920，不设上限
- `contentRect` 的坐标值在渲染后由系统自动计算

## 3.1.3 Control Schema

**文件位置**：`data/control_schema.json`

控件索引项描述，定义画布中每个控件的基本属性。

### Schema 定义

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "$id": "control",
  "title": "ControlIndexItem",
  "description": "控件索引项",
  "type": "object",
  "required": ["displayName", "image", "width", "height"],
  "properties": {
    "displayName": {
      "type": "string",
      "description": "控件显示名称"
    },
    "image": {
      "type": "string",
      "description": "控件资源路径（symbols/ 或 assets/ 下的 JSON 或图片文件）"
    },
    "width": {
      "type": ["number", "null"],
      "description": "控件宽度"
    },
    "height": {
      "type": ["number", "null"],
      "description": "控件高度"
    },
    "boundExtend": {
      "type": "number",
      "description": "边界扩展像素值"
    }
  },
  "additionalProperties": false
}
```

### 字段说明

| 字段 | 类型 | 必填 | 可为 null | 说明 |
|------|------|------|-----------|------|
| `displayName` | string | ✅ | ❌ | 控件显示名称，如 "高低温试验箱" |
| `image` | string | ✅ | ❌ | 控件资源路径，以 `symbols/` 或 `assets/` 开头 |
| `width` | number | ✅ | ✅ | 控件宽度，为 null 时由系统根据 image 自动计算 |
| `height` | number | ✅ | ✅ | 控件高度，为 null 时由系统根据 image 自动计算 |
| `boundExtend` | number | ❌ | ❌ | 边界扩展像素值，用于点击热区扩展 |

### 约束说明

1. **`additionalProperties: false`** — 严格禁止 AI 生成 Schema 未定义的字段
2. **image 路径约定** — 必须以 `symbols/` 或 `assets/` 开头，文件格式为 `.json`（矢量描述）或 `.png`/`.svg`（位图/矢量图）
3. **width/height 可为 null** — 当值为 null 时，渲染引擎根据 image 资源自动计算实际尺寸
4. **非必填字段** — `boundExtend` 仅在需要扩大点击/选中区域时设置

## 3.1.4 Binding Schema

**文件位置**：`data/binding_schema.json`（待创建）

绑点结构描述，定义控件属性与 PLC 变量的映射关系。

### Schema 定义

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "$id": "binding",
  "title": "BindingItem",
  "description": "绑点项，描述控件属性与 PLC 变量的映射关系",
  "type": "object",
  "required": ["controlId", "property", "variable"],
  "properties": {
    "controlId": {
      "type": "string",
      "description": "控件 ID，引用 control 中的 d 数组元素"
    },
    "property": {
      "type": "string",
      "enum": ["status", "value", "visible", "color", "text", "enabled"],
      "description": "控件绑定属性"
    },
    "variable": {
      "type": "string",
      "description": "PLC 变量名"
    },
    "dataType": {
      "type": "string",
      "enum": ["bool", "int16", "int32", "float", "string"],
      "description": "变量数据类型"
    },
    "registerAddress": {
      "type": "string",
      "description": "寄存器地址"
    }
  },
  "additionalProperties": false
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `controlId` | string | ✅ | 控件 ID，必须存在于 `control[].id` 中 |
| `property` | string | ✅ | 绑定的控件属性，值必须来自枚举字典 |
| `variable` | string | ✅ | PLC 变量名，如 `Pump_01_Run` |
| `dataType` | string | ❌ | 变量数据类型，来自枚举字典 |
| `registerAddress` | string | ❌ | 寄存器地址，如 `40001.0` |

### 约束说明

1. **引用完整性** — `controlId` 必须能在 `control[].id` 中找到匹配项
2. **属性枚举** — `property` 只能取枚举字典 `binding_property` 中的值
3. **数据类型枚举** — `dataType` 只能取枚举字典 `data_type` 中的值
4. **不支持反向绑定** — 绑点为单向映射（PLC → 控件），如需控件 → PLC 应通过控制脚本实现

## 3.1.5 枚举字典

**文件位置**：`data/enum_dictionary.json`（待创建）

枚举字典以独立 JSON 文件维护，通过版本管理，作为校验器唯一准入依据。

### 字典结构

```json
{
  "version": "1.0.0",
  "control_type": [
    "pump",
    "valve",
    "pipe",
    "tank",
    "indicator_light",
    "button",
    "text",
    "panel",
    "flow_meter",
    "pressure_meter"
  ],
  "binding_property": [
    "status",
    "value",
    "visible",
    "color",
    "text",
    "enabled"
  ],
  "data_type": [
    "bool",
    "int16",
    "int32",
    "float",
    "string"
  ]
}
```

### 字典类别说明

| 字典类别 | 用途 | 使用场景 |
|---------|------|---------|
| `control_type` | 控件类型枚举 | 约束 control 列表中元素的 type 字段 |
| `binding_property` | 绑点属性枚举 | 约束 binding 列表中元素的 property 字段 |
| `data_type` | 数据类型枚举 | 约束绑点、设备模型中的数据类型字段 |

### 维护规则

1. 枚举值只允许来自字典，AI 生成结果中出现字典外值判为非法
2. 字典通过版本号管理，新增枚举值需更新版本号
3. Agent Prompt 中只注入当前有效枚举值
4. 校验器加载字典后，以字典为唯一准入依据
5. 字典变更需同步更新所有相关 Schema 中的 `enum` 约束

## 3.1.6 校验规则

校验分为三个层级，逐层过滤。

### 第一层：Schema 校验

使用 `jsonschema` 库（Draft-07 解析器）执行严格校验：

| 校验项 | 规则 | 错误类型 |
|-------|------|---------|
| 字段缺失 | `required` 中的字段必须存在 | `missing_field` |
| 类型错误 | 字段值类型与 Schema 定义一致 | `type_error` |
| 多余字段 | `additionalProperties: false` 禁止未定义字段 | `extra_field` |
| 枚举越界 | `enum` 约束的值必须在允许范围内 | `enum_out_of_range` |
| 空值校验 | 非 `null` 允许的字段不能为 null | `null_not_allowed` |

### 第二层：布局规则校验

| 校验项 | 规则 | 说明 |
|-------|------|------|
| 坐标合法 | x/y/width/height 必须为整数 | 浮点数坐标会导致渲染偏移 |
| 越界检测 | 控件不能超出 canvas 范围 | x ≥ 0, y ≥ 0, x + width ≤ canvas.width |
| 重叠检测 | 控件重叠率 > 10% 报警 | 排除故意叠加的场景 |
| id 唯一 | control 列表中所有 id 不重复 | 包含嵌套控件的 id |
| 引用有效 | binding.controlId 必须存在于 control 中 | 避免悬空绑定 |

### 第三层：绑点规则校验

| 校验项 | 规则 | 说明 |
|-------|------|------|
| 类型兼容 | 控件语义与变量数据类型兼容 | bool 控件不绑定 float 变量 |
| 地址冲突 | 同一寄存器地址被多个控件绑定 | 特殊情况（如冗余显示）可忽略 |
| 变量有效 | binding.variable 存在于点表变量列表中 | 避免绑定不存在变量 |
| 属性有效 | binding.property 在 binding_property 枚举中 | 避免使用未定义属性 |

## 3.1.7 校验工具规范

基于 Python 开发 CLI 校验工具，对所有组态 JSON 执行三层校验。

### 功能规格

```
usage: validate.py [-h] --json JSON_FILE [--schema-dir SCHEMA_DIR]
                   [--enum-file ENUM_FILE] [--output {json,text}]

对组态 JSON 文件执行 Schema + 枚举 + 规则校验

options:
  --json JSON_FILE         待校验的组态 JSON 文件路径
  --schema-dir SCHEMA_DIR  Schema 文件目录（默认 data/）
  --enum-file ENUM_FILE    枚举字典文件路径（默认 data/enum_dictionary.json）
  --output {json,text}     输出格式（默认 text）
```

### 校验流程

```text
1. 加载 JSON 文件
2. 根据 JSON 结构自动匹配 Schema（canvas / control / binding）
3. 执行 JSON Schema Draft-07 校验
4. 加载枚举字典，执行枚举值校验
5. 执行布局规则校验
6. 执行绑点规则校验
7. 汇总错误列表，生成校验报告
```

### 输出格式

```json
{
  "valid": false,
  "schema": "canvas_schema.json",
  "total_errors": 2,
  "errors": [
    {
      "path": "/a/width",
      "error_type": "missing_field",
      "message": "缺少必填字段 'width'",
      "suggestion": "请添加 'a.width' 字段，类型为 number"
    },
    {
      "path": "/control/2/displayName",
      "error_type": "type_error",
      "message": "字段 'displayName' 类型应为 string，实际为 number",
      "suggestion": "请将 displayName 的值改为字符串"
    }
  ]
}
```

### 校验结果定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `valid` | boolean | true 表示所有校验通过 |
| `schema` | string | 使用的 Schema 文件名 |
| `total_errors` | number | 错误总数 |
| `errors` | array | 错误列表，每项含 path/error_type/message/suggestion |

### 验收标准

1. 合法 JSON 文件判断为 `valid: true`，准确率 100%
2. 非法 JSON 文件至少能识别 1 个错误，准确率 100%
3. 至少提供 3 个合法示例和 3 个非法示例，均能被正确识别
4. 枚举越界、字段缺失、类型错误三类错误必须能区分 `error_type`

## 3.1.10 性能设计说明

### 后端性能（≤500ms、跨平台）

| 性能指标 | 设计保障 |
|---------|---------|
| 校验耗时 | JSON Schema Draft-07 校验为单次遍历 O(n)，典型组态 JSON（200 控件）校验耗时 ≤10ms，远低于 500ms 预算 |
| 集成方式 | FastAPI 中间件/依赖注入方式调用，校验处于请求-响应关键路径之外（Agent 生成后再校验），不占用接口响应预算 |
| 跨平台 | `jsonschema` 库为纯 Python 实现（MIT 开源协议），无 C 扩展依赖，Windows Server 2019+ / CentOS 8+ 均可通过 `pip install` 部署 |
| 内存占用 | Schema 文件和枚举字典为纯 JSON，按需加载，内存占用 < 1MB |

### 第三方依赖

| 依赖项 | 版本 | 用途 | 兼容性 |
|-------|------|------|--------|
| `jsonschema` | ≥4.20（Python） | JSON Schema Draft-07 校验引擎 | 纯 Python，Python 3.10+ |
| 枚举字典 `data/enum_dictionary.json` | 系统内建文件 | 枚举值硬编码准入 | 版本号管理，变更通过 Git 追溯 |

规则库为纯离线校验基础设施，不涉及任何外部 API 调用，无故障率风险。
