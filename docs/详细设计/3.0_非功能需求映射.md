# 3.0 非功能需求映射

本文档汇总系统性能要求与各详细设计模块的对应关系，用于需求评审和验收追溯。

---

## 3.0.1 后端技术（FastAPI、≤500ms、跨平台）

| 需求 | 指标 |
|------|------|
| 框架 | FastAPI，支持异步高并发 |
| 接口响应时间 | ≤500ms（不含第三方 API 调用耗时） |
| 跨平台 | Windows Server 2019+、CentOS 8+ |

### 各模块时间预算汇总

| 模块 | 章节 | 关键路径 | 非 LLM 耗时预算 | 关键技术保障 |
|------|------|---------|:---------:|-------------|
| 3.1 JSON Schema 规则库 | 3.1.10 | Schema 校验 | ≤10ms | 单次遍历 O(n)，`jsonschema` Draft-07 |
| 3.2 控件素材库 | 3.2.10 | Chroma 向量检索 + SQLite 兜底 | ≤300ms | 向量检索 ≤200ms + LIKE ≤50ms；watchdog 异步监听 |
| 3.3 控件素材 Agent | 3.3.12 | 多路检索（缓存命中场景） | ≤300ms | LLM 意图提取缓存；Chroma+SQLite 合计 ≤250ms |
| 3.4 自动布局 Agent | 3.4.8 | Zonal 布局 / 力导向布局 + 质量检测 | ≤500ms | Zonal O(n)≤100ms；力导向≤400ms；质量检测≤50ms |
| 3.5 人机微调 Agent | 3.5.12 | Patch 校验 + 规则修复 | ≤50ms | PRD 要求 ≤1000ms（不含 LLM）；校验 ≤50ms |
| 3.6 数据绑点 Agent | 3.6.15 | 三路匹配 + 消歧 + 冲突检测 | ≤800ms | 语义≤500ms；模糊≤200ms；匈牙利≤50ms |

> **说明**：各模块 LLM API 调用均排除在 500ms 预算外。模块中的纯计算/检索链路需各自满足 ≤500ms（3.5 为 ≤1000ms，3.6 因 N×M 矩阵规模较大放宽至 ≤800ms）。

## 3.0.2 第三方依赖（LLM API、故障率≤0.5%、版本兼容性）

| 需求 | 指标 |
|------|------|
| 接口调用稳定 | 故障率 ≤0.5% |
| 版本说明 | 所有第三方依赖需提供版本说明及兼容性证明 |
| 选型 | 开源或经甲方确认的商业接口 |

### 各模块第三方依赖汇总

| 模块 | 章节 | 依赖项 | 用途 | 降级策略 | API 调用参数 |
|------|------|-------|------|---------|------------|
| 3.1 JSON Schema 规则库 | 3.1.10 | `jsonschema`（Draft-07） | JSON Schema 校验 | 纯离线 | 无 API 调用 |
| 3.2 控件素材库 | 3.2.10 | `bge-small-zh-v1.5`（本地）、DeepSeek API、ChromaDB | Embedding 向量化、LLM 意图提取 | Embedding 本地部署无依赖；LLM 失败→ SQLite LIKE 兜底 | — |
| 3.3 控件素材 Agent | 3.3.12 | DeepSeek API | 意图提取 | 缓存命中跳过 API；调用失败→标记 `missed`，不阻塞 | `reasoning_effort=low`，超时 50s |
| 3.4 自动布局 Agent | 3.4.8 | DeepSeek API | 布局需求提取 + 坐标微调 | LLM 调用失败→降级为启发式规则分类（关键词匹配） | `reasoning_effort=low`，超时 50s |
| 3.5 人机微调 Agent | 3.5.12 | DeepSeek API | Patch 生成 + 修复 | 确定性错误规则修复（不调用 LLM）；生成失败→confidence=0 | `reasoning_effort=medium`，`temperature=0.3` |
| 3.6 数据绑点 Agent | 3.6.15 | DeepSeek API（辅助）、`bge-small-zh-v1.5`（复用 3.2） | 低置信度消歧 | LLM 非主力引擎，API 不可用→跳过，不影响主匹配路径 | 仅低置信度且 fuzzy<0.3 时调用 |

### 第三方依赖版本清单

| 依赖项 | 类型 | 部署方式 | 版本 | 兼容性说明 |
|-------|------|---------|------|-----------|
| FastAPI | Web 框架 | pip 安装 | ≥0.110 | Python 3.10+，Windows/Linux |
| `jsonschema` | 校验库 | pip 安装 | ≥4.20 | 纯 Python，跨平台 |
| ChromaDB | 向量数据库 | pip 安装 + 本地持久化 | ≥0.5 | 离线运行，内嵌 DuckDB+SQLite |
| `bge-small-zh-v1.5` | Embedding 模型 | 本地文件加载 | 固定版本 | HuggingFace 下载后本地使用，使用 `SentenceTransformer` 加载 |
| DeepSeek API | LLM 服务 | HTTP API（OpenAI 兼容） | `deepseek-chat` | 通过 `openai` SDK 调用，base_url 可配置 |
| `openpyxl` | Excel 解析 | pip 安装 | ≥3.1 | 纯 Python，跨平台（3.6 绑点 Agent 使用） |
| `watchdog` | 文件监听 | pip 安装 | ≥4.0 | 跨平台文件变更监听（3.2 素材库使用） |

### 故障率保障策略

| 策略 | 说明 |
|------|------|
| **熔断** | LLM API 连续失败 3 次后进入熔断状态，后续请求直接走降级路径，30s 后半开尝试恢复 |
| **重试** | LLM API 单次失败重试 1 次，间隔 1s |
| **降级** | 各模块均有 LLM 不可用时的降级路径（启发式规则/SQLite 兜底/标记 missed/跳过），不阻塞主流程 |
| **超时** | LLM 调用统一超时 50s（3.4/3.3/3.5）；纯计算/检索链路无单独超时，依赖 FastAPI 请求级别超时 |
| **监控** | 日志记录每次 LLM 调用耗时、成功/失败状态，用于统计故障率 |
